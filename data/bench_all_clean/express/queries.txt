`sendfile` should call the provided `fn` callback on `finish` Basically the following is an excerpt from [`res.sendfile()`](https://github.com/visionmedia/express/blob/master/lib/response.js#L317) code: ``` res.sendfile = function(path, options, fn){ .... // cleanup function cleanup() { req.socket.removeListener('error', error); } ... this.on('finish', cleanup); }; ``` When sending the file is done, it calls `finish` which calls `cleanup`. That's all. Nobody calls `fn` callback. This causes a problem that the callee flow never ends. For instance, I use `async.waterfall`. In the last callback flow I send a file which should call its callback. Then the last error callback is called and the async flow is completed. Since `sendfile` never calls the callback, the main async flow never completes. Ideally, it should: ``` this.on('finish', function () { cleanup(); if (fn) fn(); }); ``` I can send a PR if necessary.
